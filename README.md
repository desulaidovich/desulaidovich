### 🚀 [plea-cli](https://github.com/desulaidovich/plea-cli)

CLI-инструмент для генерации Go-проектов из готового шаблона с современными практиками:

*   **Functional options** для конфигурации
*   **Структурированное логирование** (slog, JSON/text)
*   **Graceful shutdown** через errgroup и перехват сигналов
*   **Build-time version** через ldflags
*   **Makefile** для удобной сборки и запуска

📦 Установка: `go install github.com/desulaidovich/plea-cli@v0.0.1-dev`
